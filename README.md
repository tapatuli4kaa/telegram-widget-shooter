# Рейкастер-шутер в Telegram-виджете

Бот на Bot API 10.4 (`sendWidget`). Зависимостей нет, нужен только Node 18+.

## Запуск

1. Скопируй `.env.example` в `.env` и впиши `BOT_TOKEN`. Если виджеты пока работают только в бете, раскомментируй `BOT_API=https://api.telegram.org/beta`.
2. `node bot.mjs`
3. В личке с ботом отправь `/shooter`.

## Bad Apple (в боте отключён)

Код плеера и кодека лежит в `badapple/`, но бот его больше не отправляет.

Виджет весит не больше 4 КБ после zlib и не может ходить в сеть, поэтому видео в него не помещается. Его стримит бот.

- **Кодек** (`badapple/codec.mjs`). Кадры однобитные. Каждый пиксель сжимается адаптивным бинарным range-кодером. Контекст пикселя — 12 бит: 7 соседей в текущем кадре и 5 в предыдущем (как в JBIG). Если кадр не изменился, он кодируется одним битом. На выходе весь клип занимает 144 КБ, то есть около 44 байт на кадр.
- **Транспорт.** Бот пишет в `chat_data` сообщения строку вида `<seq>:<base64>`, до 1024 байт. Это примерно 16 кадров, или 1,1 с видео. Правка идёт раз в секунду, так что поток успевает в реальном времени. Виджет получает `chatDataChanged`, складывает чанки в буфер и после 3 с запаса начинает играть.
- **Потери.** Если чанк потерялся, виджет запрашивает его фоновым `request('get:N')`. Если клиент такие запросы не разрешает, появляется кнопка «⟳ Resync».
- **Отрисовка.** Белые участки строк кадра собираются в один `Path2D`, так что на кадр уходит один вызов `fill`.
- **CPU.** В QuickJS из песочницы декодирование занимает ~50 мс на секунду видео при бюджете 300 мс.

Перекодировать видео с другим разрешением или fps:

```bash
node badapple/encode.mjs video/bad_apple.mp4 96 72 15
```

`node badapple/make-preview.mjs` собирает `badapple/preview.html`: плеер с имитацией бота, который можно открыть в обычном браузере.

## Шутер

`shooter/widget.html` — свой рейкастер, ~3,9 КБ после zlib.

- **Управление.** Кнопки ⟲ ▲ ▼ ⟳ работают на удержание. FIRE или тап по экрану — выстрел. Горизонтальный свайп по экрану поворачивает камеру.
- **Игра.** Волны красных демонов, мини-карта, рекорд хранится в `localStorage`. Враги ищут путь к игроку поиском в ширину по клеткам карты и обходят стены.
- **CPU.** Цикл работает только во время игры: до первого нажатия, через 15 с без ввода и на экране смерти он стоит. Во время игры ~270 canvas-команд и ~0,6 мс JS на кадр.
